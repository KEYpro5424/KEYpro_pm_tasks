# 新規事業 進行ボード

全体の流れ・方針・取引先・ToDoを1か所で管理するためのブラウザ上で動く進行管理ボードです。

## 特徴
- **オールインワン**: スケジュール（ガントチャート）、ToDoリスト、打ち合わせメモ、見積もり計算などを1つの画面で切り替えて管理できます。
- **データ保存**: 入力したデータは自動的にブラウザのローカルストレージに保存されるため、リロードしても消えません。
- **静的ホスティング対応**: GitHub Pages などの静的サイトホスティングサービスにそのままデプロイして使用できます。

## 使い方
1. リポジトリをクローンまたはダウンロードします。
2. フォルダ内の `index.html` をブラウザで開くだけで動作します。
3. GitHub Pagesを使用する場合、リポジトリの設定（Settings） > Pages から、対象のブランチを選択するだけで公開可能です。

## 技術構成
- HTML5
- CSS3 (Vanilla / Custom Properties)
- JavaScript (Vanilla JS / フレームワーク不使用)
